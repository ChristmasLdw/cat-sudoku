# 猫猫数独 Cat Sudoku

原创、无依赖的浏览器逻辑游戏。界面和猫咪 SVG 为本项目编写，没有使用参考截图的商标或图像。55 个原有关卡为本项目生成；另有 7 个测试棋盘按用户提供的截图还原颜色区域。纯静态文件，无需数据库、账号、API Key 或安装依赖。

## 直接玩

- 单文件：打开随包提供的 cat-garden.html（在源码文件夹外）。所有样式、关卡和逻辑都已内嵌，可离线运行。
- 源码版：保持 index.html、styles.css、engine.js、trial.js、levels.js、hints.js、tutorial.js、journey.js、app.js 在同一文件夹，双击 index.html。
- 使用支持 JavaScript 的现代 Chrome、Edge、Firefox 或 Safari。浏览器预览测试使用 Chromium；未逐一测试其他浏览器。自动浏览器不允许 file:// 导航，因此本地双击入口没有做自动端到端验证；已校验单文件脚本语法与内嵌资源，并在 HTTP 预览验证同一套游戏源码。

## 上传到你的网站

1. 在网站静态文件目录创建 cat-sudoku 文件夹。
2. 上传上述九个源码文件，保持文件名和相对位置。
3. 访问网站的 /cat-sudoku/index.html。没有构建命令或后端服务。

也可以只上传单文件 cat-garden.html，然后访问它的地址。不要把代码粘贴到会过滤 script 标签的富文本编辑器；应当作为 HTML 文件上传。

上传目录可以换名字，代码使用相对资源路径。你的服务器应以 text/html 提供 HTML，以 text/css 提供 CSS，以 text/javascript 或 application/javascript 提供 JavaScript。

## 嵌入现有网页

将下面的路径换成实际上传的位置：

    <iframe
      src="/cat-sudoku/index.html?embed=1"
      title="猫猫数独逻辑小游戏"
      style="display:block;width:100%;height:900px;border:0;border-radius:20px;"

embed=1 会隐藏顶部品牌名称，保留设置和选关按钮。游戏采用单栏布局，iframe 内可滚动；可按宿主页面需要调整高度。embed-example.html 是可直接打开的嵌入示例。单文件版也支持 ?embed=1。宿主网站须允许 iframe；跨域嵌入时，游戏服务器的 frame-ancestors / X-Frame-Options 配置须允许你的宿主网站。

## 规则与操作

- 每行、每列、每个颜色区域必须恰好有一只猫。
- 任意两只猫不能相邻，包括斜角。
- 默认“快捷”模式：单击空格标 ×，再单击清空；快速双击同一格确认猫咪（两次点击间隔约 420 毫秒内），单击已有猫可清空。双击放猫只需一次撤销即可恢复到点击前；也支持手机连点两下。
- “放猫”“标记”模式可直接切换猫或 ×；右键直接切换 ×。
- 按住鼠标左键拖动，或在棋盘上按住手指滑动，可连续标 ×；从已有 × 开始会连续擦除。约 260 毫秒长按或移动超过 7 像素进入涂抹。一笔手势只记录一次撤销，重复划过同一格不会来回切换，已有猫咪不会被覆盖。
- 点击、放猫、擦除和通关有本地合成音效，首次手动操作后才启动声音；不下载任何音频文件。放猫音效叠加落点、上扬拨弦与泛音，随猫咪数量变化；假设猫使用独立提示音。音效表示当前没有直接规则冲突，不代表这个位置已经被证明正确。点击有轻微弹跳，通关有短暂彩纸动画。
- 左上角设置中可以关闭音效或动画、开启区域字母和设备振动；系统减少动态效果偏好会自动抑制动画。振动需要设备和浏览器支持，未在实体手机上验证。设置偏好保存在本机浏览器；当前棋盘标记仍只在当前页面会话内保留，单元完成记录会保存。
- 右上角“选关”打开 62 关列表，重置按钮在设置中。打开设置或选关时暂停计时。
- × 是玩家笔记，不参与正确答案判定，也不会自动排除其他格。
- 默认开启棋盘内的冲突标记；普通操作不再自动弹出文字提示。点击“检查”才在原盘高亮候选、显示缺猫的行/列/颜色数量；已经无处放猫时高亮对应区域。普通玩法和假设模式都适用。缺猫但仍有可用位置仅表示未完成，不算错误；这些检查不会给出答案，也不保证所有深层矛盾都能发现。
- 猫的数量正确且没有任何规则冲突时自动通关；无需把其他格全部标 ×。
- 撤销支持多步，普通撤销不会减少用时。重置会清空棋盘并归零计时；撤销重置可恢复此前的棋盘与计时。
- 首次改动开始计时；暂停、切到其他关卡、页面进入后台和通关时暂停计时。
- 方向键移动焦点；空格 / Enter 操作；X 标记；C 放猫；Delete / Backspace 清空；Ctrl / Command + Z 撤销。
- 颜色之外还有区域字母，便于区分；支持键盘操作和减少动画偏好。

当前棋盘的标记与计时仅保留在本次页面会话内：切换关卡可以回来继续，刷新或关闭页面会清空这些标记；单元学习与完成记录另外保存。没有联网记录、广告或第三方请求；设置偏好、教学与单元完成记录使用本地存储。直接打开本地文件可离线玩；从网站访问时首次加载仍需联网，本项目未注册离线缓存服务。

## 稳定布局与悬浮提示

假设操作的四个按钮始终占据固定位置，不适用时变灰。已移除右上角自动提示及右下角消息入口。普通点击、撤销、检查结果变化、开始和撤回假设都不会自动弹窗。用户点“提示”或“检查”才显示棋盘旁的浮层，原盘尺寸及按钮位置保持不变。关闭、Esc、切关、打开设置或暂停会清理提示。通关仍显示完成卡片。

这些关卡只保留颜色区域，初始状态与重置后均没有猫或 ×，也没有教学预置猫或自动教学。撤销、假设、检查及按需推理提示仍可使用。颜色与截图保持对应；全部通过区域连通性及唯一解校验。原有 55 关的顺序和 ID 不变。

## 单元闯关与按需提示

55 个关卡编排成 10 个单元。保留难度递进与单元技巧目录，进入关卡不再自动弹出教学。用户可以主动点“提示”、单元技巧入口或“技巧图鉴”，在真实棋盘上查看线索。每单元的闯关数依次为 2、2、3、4、5、6、7、8、8、10。单元入口按顺序介绍：

1. 初次见面：单击与双击，2 关。
2. 轻轻划过：按住拖动批量标叉，2 关。
3. 留一点距离：周围八格与斜角，3 关。
4. 唯一的家：一种颜色只剩一格，4 关。
5. 横竖找一找：行或列只剩一格，5 关。
6. 颜色有边界：颜色锁定行列，6 关。
7. 换个方向想：行列反向锁定颜色，7 关。
8. 成双的线索：两色占两行／列、两行／列只剩两色，8 关。
9. 大胆试，小心退：假设导致其他颜色无处放猫、反证与撤回，8 关。
10. 自由探索：综合运用，10 关。

引导直接使用当前棋盘，不再打开另一块练习棋盘，也没有上一步 / 下一步。发光格缓慢呼吸，细线图形是待操作预览；说明悬浮在棋盘上方或侧边，不改变棋盘和按钮位置。实际点击、双击、拖动完成后自动收起。尚不满足技巧条件时等待局面变化，不为了教学偷偷添加猫或标记。关闭引导可继续自由玩；技巧图鉴可查看 15 条说明，并在当前棋盘寻找适用位置。暂停、设置、选关期间隐藏引导，返回后恢复；切关或通关清理高亮。系统减少动态效果及关闭动画均会禁用呼吸动画。

关卡按 5×5 至 9×9 排列。为避免前期出现超出已介绍技巧的推理，前 8 单元部分关卡带预先安置的固定猫（角标“定”），不可删除。前两关为只需补一只猫的热身；其余带线索的棋盘经过规则提示路径验证，可在该单元的技巧范围内完成。后两单元不带额外固定猫，保留完整挑战。原始 regions 数据及全部 55 个关卡 ID 不变；这是一种引导编排，不是经过用户实验标定的精确难度。

单元学习记录、已完成关卡和当前位置保存在当前浏览器。当前棋盘内的标记与计时仍仅在本次页面会话保留，刷新会从该关初始线索重开。记录不跨设备同步；禁用或清空本地存储后会重新开始引导。

“推理提示”根据当前猫位和 ×，先检查冲突和是否还存在合法完成方式，再寻找已占用位置的排除、唯一候选、行列与颜色的锁定、两色与两行／列的对应限制，以及单格假设导致另一种颜色候选清空。没有找到这些技巧能确定的下一步时，会建议选一组候选进行假设，不伪装成确定答案。

提示直接叠加在原棋盘，不再创建第二张预览棋盘：金框标依据、虚线猫/叉标结论，无关格淡化。行列锁定会在对应行列画框，假设反证用“假”标记和连线指出会被封死的区域。浮层只显示短句、颜色方块和箭头；完整推理默认折叠。直接在亮格操作或点“快速应用”均可，完成后自动收起；应用整步可一次撤销。逐格排除期间保留剩余目标，改动无关格会清掉旧结论。检查时亮点表示合法候选，缺猫但还有位置不算错误。假设中的提示仅属于本轮推演。

“检查”提供规则检查，“提示”给出可操作的下一步，两者使用同一个原盘可视化浮层。生成器追加的新关卡默认进入最后的自由探索单元；若要纳入更早的教学节奏，应更新 journey.js 的编排与固定猫，并重新验证。

## 假设推演

1. 拿不准二选一时，点击“开始假设”，再点选想尝试的位置。系统保存当前棋盘，在起点放一只带“假”字的猫。
2. 正常继续放猫、标叉；本次推演中改动过的格子以金色标记。假设起点暂时锁定，避免忘记自己正在尝试哪个选择。
3. 同行、同列、同区或相邻猫产生冲突，或者某行、列、区域已经无处放猫时，主动点击“提示”或“检查”会显示矛盾。这里把你的 × 也当作排除条件；没有提示不代表已证明假设正确，错误的中间排除也可能造成矛盾。
4. “撤回假设”：完整恢复开始前的棋盘，起点留下“试”字，表示试过但未排除。
5. “排除起点并撤回”：恢复开始前的棋盘，同时仅把起点标为 ×，留下“排”字，方便继续尝试另一个选择。这是玩家主动确认的排除，不会因为系统发现矛盾就自动执行。
6. “保留推演”：结束假设，保留当前棋盘。有已发现的矛盾时不能保留。

撤回、保留和开始假设都可以通过普通“撤销”恢复；一次只进行一个假设。切换关卡会保留各关的假设，刷新或关闭页面会清空。修改以前的试验起点后，该格的“试”或“排”标签会移除。

## 添加关卡

### 自动生成（推荐）

安装 Node.js 后，在源码文件夹打开终端，执行：

    node generate-levels.cjs --size 7 --count 10 --append

这会生成 10 个 7×7 的新关卡，保留并追加到现有 levels.js，写入前自动备份旧文件。刷新源码版游戏即可看到新关卡；如果你使用单文件版，再执行：

    node build-single.cjs

然后重新上传生成的 cat-garden.html。源码版网站只需更新上传 levels.js。

- --size：5–9，指定棋盘尺寸。
- --count：1–100，指定这一批要生成多少关。
- --seed：可选，固定随机种子；相同参数和现有关卡集会得到相同结果。省略时每次随机。
- --append：自动加入游戏，并保留原来的所有关卡。
- --output extra-levels.json：只输出独立 JSON 数据，不修改游戏；不能与 --append 同时使用。已有输出文件不会被覆盖。
- --max-attempts：整批候选棋盘的尝试上限，默认 200000。达到上限会明确报错，且不保存部分结果。可降低数量、换种子或提高上限后重试。

例如生成 5 个 9×9 关卡：

    node generate-levels.cjs --size 9 --count 5 --append

生成流程：先生成合法猫位，再从猫位向上下左右扩展区域，最后用求解器检查。发现第二个答案就淘汰该棋盘；相同布局、颜色编号变化、旋转和镜像重复也会排除。区域可能只有一格，可作为推理起点。尺寸不是精确难度等级：唯一解并不保证只用简单推理即可解出，建议试玩后筛选。

随包的 extra-levels.json 是已经生成并验证过的 10 个 7×7 新关卡数据，供参考；它不会自动加载到游戏。需要直接增加可玩关卡时使用上面的 --append 命令。

若要恢复追加前的关卡，用自动创建的 levels.js.<时间>.bak 替换 levels.js，再按需重新生成单文件。备份不会自动删除。

### 手工编写

编辑 levels.js 的 levels 数组，在其中添加对象。格式如下（结构示例的矩阵请使用实际有效数据，不要直接填写占位符）：

    {
      id: "my-level",       // 不重复的字符串
      name: "我的花园",     // 页面显示的名称
      size: 5,              // 整数，支持 4 至 9
      regions: [            // size 行，每行 size 个整数
        // 每格为 0 至 size-1 的区域编号
      ]
    }

一个 size×size 的棋盘恰有 size 个区域，编号连续，从 0 开始。同一区域必须通过上下左右连通；编号 0 显示为区域 A，依次类推。行列索引在代码内从 0 开始，界面从 1 开始。棋盘是一维数组，第 r 行第 c 列对应 r * size + c；0=空白、1=×、2=猫。

推荐复制某个现有关卡作为格式参考，修改 id、name、size、regions，并在发布前运行测试。不要仅依赖唯一解来判断难度；示例按尺寸排列，没有宣称精确的难度等级。

浏览器开发者控制台可调用：

    CatPuzzle.validateLevel(CAT_LEVELS[0]);
    CatPuzzle.solve(CAT_LEVELS[0], 2).length;

solve 的第二个参数是最多返回的答案数：结果长度为 0 表示无解，为 1 表示唯一解，为 2 表示至少两解。每个答案是按行排列的猫咪列号，均从 0 开始。该函数用于作者验证，游戏界面不会展示答案。
